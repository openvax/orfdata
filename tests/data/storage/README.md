These synthetic databases were generated by the **released** ORFdata versions
0.3.0 (storage 1), 0.4.0 (storage 2), 0.5.0 (storage 3) and 0.30.0 (storage 4),
using `generate.py`.
They test actual legacy layouts; changing a new database's `user_version` would
not produce a valid old-format fixture.

Each contains four species with colliding local sample/assay/target/measurement
IDs, measured zero, a censored value, uncertainty and derived input lineage.
Versions 2-4 include pairings; versions 3-4 include reference mappings, and
version 4 includes target mappings. No records
are experimental evidence. The JSON files retain the original writer's records.

Example regeneration from a checkout of the appropriate release:

```sh
PYTHONPATH=/path/to/orfdata-0.3.0 python generate.py /path/to/fixtures 1
```
