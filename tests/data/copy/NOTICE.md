These are unmodified numeric slices of Lawless et al. (2016),
https://doi.org/10.1074/mcp.M115.054288, supplemental Data S1 (CC-BY-4.0),
and GEO GSE73898 (NCBI places no restrictions on GEO data reuse).
The full 6,581-row RNA worksheet is retained to reproduce the 60,000-mRNA
normalization. `expected.json` records original Excel row numbers for the
smaller protein/peptide/label-free slices. The synthetic QconCAT FASTA is
complete; it is calibration material, not the native yeast proteome.

Each of four GEO tables retains an AMD1 observation, a positive LOWDATA value
and a measured zero. Metadata files are explicitly marked test stubs pointing
to the pinned primary objects; they are not copies of the source documents.
Fixture source hashes describe the fixture files, with primary URL/hash in
metadata. Use local source overrides; fixture URLs intentionally do not resolve.
