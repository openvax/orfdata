These small fixtures are actual rows from the March 23, 2026 Pfizer/Oziolor
protein summaries, with the corresponding deposited UniProt FASTA records.
`expected.json` records original table line numbers, exact native fields and
the complete source manifest. Fixture manifests separately pin the slice bytes;
they do not claim that a slice is the complete source release.

MSV000099744 (dog), CC0-1.0 as stated on each dataset deposit.
Search FASTA metadata and sequences: UniProt Consortium, CC-BY-4.0.

Study: Oziolor et al., *Quantitative transcriptome and proteome maps of classical
nonclinical species*, Scientific Data (2026), DOI 10.1038/s41597-026-07512-9.
The article license is separate from the deposited numeric-data license.
